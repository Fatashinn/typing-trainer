# Typing Trainer 2.0: мультиязычная учебная платформа

Актуальная спецификация заменяет прежние ограничения RU/EN и одного файла.
База реализации: main `26861845`, после объединённых PR #1 и #2.
Реализация ведётся отдельной веткой; слияние и публикация — решение владельца.

## Продуктовые правила

- Статический сайт для GitHub Pages; без обязательного backend, регистрации,
  платного сервиса или внешней передачи учебных данных.
- Независимые UI language, typing language, input layout и physical geometry.
- UI ru/en; первые языковые пакеты ru/en/fr/de; расширяемые реестры.
- Все упражнения доступны сразу. Карта и адаптивная рекомендация не блокируют
  свободный выбор. XP не равен мастерству.
- Старые данные не объявляются подтверждённым новым мастерством или XP.
- Источники раскладок и уровень поддержки явно указаны. Справочная карта
  не является доказательством работы современного Mac или аппаратного ISO.
- Приложение не управляет системными раскладками и не определяет фактический палец.

## Реализованный первый вертикальный срез 2.0

- Локальные модули и регистрация языковых пакетов/раскладок без сборки.
- ru/en локализация UI, включая сохранённые функции 1.x и новый интерфейс.
- Содержательные пакеты ru/en/fr/de; семь начальных справочных карт,
  разделённые Option/AltGr, dead-key маршруты и NFC.
- Ручной выбор контекста, нативные input/composition события в новых уроках,
  предупреждения о неподдерживаемых символах и экспериментальных картах.
- Быстрая/полная диагностика и пропуск; частичное покрытие явно обозначается.
- 42 открытых узла из общего механизма, практика, испытания и критерии.
- Независимые физические, символьные, языковые и парные наблюдения;
  прозрачные пороги состояний и рекомендации. Наблюдаемые слабые символы
  повышают долю соответствующего материала в практике.
- Свободная практика и смешанное упражнение с двумя выбранными контекстами.
- XP, уровень, пять достижений и идемпотентная обработка результатов.
- Схема платформы v1, экспорт копии v2 всех восьми ключей, импорт старого v1
  без удаления нового прогресса. Никаких ретроспективных игровых наград.
- Сохранены функции стабилизации 1.x, старые режимы и статистика.

## Следующий срез: проверка реального ввода

1. Zen/macOS на MacBook Air M2: все установленные источники ввода,
   Option, AltGr на соответствующей ОС, dead keys, Caps Lock и Ctrl+Space.
2. Подтвердить или скорректировать архивные macOS-карты; хранить отдельные
   версии определений, не менять семантику уже сохранённых layout id молча.
3. Проверить ANSI/ISO физически. Полная геометрия ISO Return не заявлена.
4. Добавить подтверждённые современные PC-варианты, UK, US International,
   Swiss, BÉPO, Dvorak, Colemak по отдельным источникам и тестам.

## Следующий срез: учебное качество

- Калибровать пороги на реальных данных, показывая неопределённость.
- Расширить частотные корпуса и естественные материалы без потери покрытия.
- Улучшить план диагностики для ограниченных раскладок и оценку переноса навыка.
- Более подробный графический анализ навыков и сравнимых условий практики.
- Доработать UX карты, сохранив прямой доступ к упражнениям и доступность.
- Продумать архивирование больших историй без удаления id и повторного XP.

## Следующий срез: ИИ

Сначала развивать ручной аналитический отчёт с контекстом языка/раскладки,
подсказок, повторов и надёжности. Формат отчёта отделён от резервной копии.
Прямую интеграцию, приватность и работу с ключами обсуждать отдельно.
Внешний сервис не должен быть условием обычной тренировки.

## Критерии ревью

Полный автоматический прогон, перенос старой копии, сохранность прогресса,
отсутствие повторных наград и ручной сценарий Zen перед слиянием. Проверки
Chromium не выдаются за аппаратную или Firefox-совместимость.
Подробности: ARCHITECTURE.md, LAYOUTS.md, LANGUAGE_PACKS.md, MASTERY.md,
MIGRATIONS.md, I18N.md и ZEN_TESTING.md.
