# Ручная проверка 2.0 в Zen / macOS

Не обновляйте рабочий сайт ради проверки. Сохраните резервную копию Pages,
создайте отдельный профиль Zen и откройте локальный сервер новой ветки:

```bash
git clone --single-branch --branch feat/multilingual-platform https://github.com/Fatashinn/typing-trainer.git typing-trainer-2-review
cd typing-trainer-2-review
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/` в тестовом профиле. Данные Pages и localhost
принадлежат разным origins. Не удаляйте существующие рабочие каталоги.

1. Импортируйте старую копию v1: проверьте настройки/историю/собственный текст
   и старую серию. Нового XP и подтверждённого мастерства от старых данных нет.
2. В настройках выберите русский UI, французский материал, French macOS и
   ANSI. Они независимы: затем смените только UI на English и обратно.
   Прогресс и текст черновика должны сохраниться.
3. В системе выберите именно указанную раскладку. Проверьте прямые знаки,
   Option, Shift слева/справа, Caps Lock, `é è à ç œ`, составные `ê ë`.
   Промежуточный dead key не должен считаться ошибкой, финальный символ —
   ровно один ввод. Карты macOS архивные и экспериментальные: записывайте
   несовпадения code/key и источник ОС, не делайте вывод о виновной технике.
4. Повторите на немецком (`ä ö ü ß`, QWERTZ) и двух русских источниках
   Russian / Russian – PC. Они не идентичны. French/German PC проверяются
   отдельно на соответствующей системной раскладке, а не как синонимы Mac.
5. French PC не имеет `œ` в принятом справочнике: диагностика должна явно
   показать частичное покрытие. Невозможный учебный узел не должен молча
   удалять обязательный символ или объявлять его освоенным.
6. Пройдите быструю диагностику, полную и вариант «Пропустить». Все узлы
   остаются открыты; один результат не даёт фиктивного освоения всех клавиш.
7. На карте откройте обучение, практику и испытание. Подсказка меняется
   существующим селектором. В статистике проверьте контекст языка/раскладки,
   отдельные символы и физические клавиши; фактический палец не определяется.
8. Выберите вторые язык/раскладку и запустите узел переключения (Техника 3).
   Вручную используйте Ctrl+Space между участками. Ожидаемая экранная карта
   меняется; системную карту приложение не переключает. Результаты контекстов
   не должны смешиваться.
9. Выполните осмысленное упражнение без подсказок: после ≥15 секунд активности
   и ≥20 неповторных событий при достаточной точности появляется XP. Проверьте
   уровень/достижения, затем перезагрузите страницу дважды — XP не удваивается.
   Простои и удержание клавиши не должны выдавать награды.
10. Проверьте Ctrl+Space, Cmd+Tab, паузу, длинные тексты, повторы, маленькое окно,
    обе темы и настоящий zoom 200%. В составе упражнения нужно печатать в
    обозначенное поле нативного ввода; вставка не засчитывается как навык.
11. Экспортируйте копию v2 и импортируйте в другой тестовый профиль. Сравните
    контексты, мастерство, XP, достижения и старые данные. Импорт v1 поверх
    прогресса 2.0 должен оставить платформенные данные на месте; v2 — полная
    подтверждённая замена. Перед импортом закройте остальные вкладки.
12. В старых режимах повторите базовую тренировку, дневные блоки и продолжение
    собственного текста. Эти режимы сохраняют свой путь совместимости 1.x.

ISO — отдельная аппаратная проверка: дополнительная клавиша, Backquote,
IntlBackslash, Return и browser code. До неё полная поддержка ISO не заявляется.

Не воспроизводите нехватку места на рабочем профиле. Автотесты моделируют
отказы и восстановление в изолированном хранилище. Перед отправкой снимков
консоли удаляйте личный текст; значения localStorage публиковать не нужно.
