# Языковые пакеты

`platform/languages.js` поставляет ru/en/fr/de независимо от языка UI и карты
ввода. Каждый пакет содержит родное имя, алфавит, частотный порядок, слова,
сочетания, предложения, пунктуацию и перечень типов заданий. Контент NFC,
не переводится системой интерфейса. В каждом начальном пакете более 70 слов
и десять предложений; это стартовый учебный материал, не корпусная модель языка.

```javascript
TT2.registerLanguage({
  id: 'xx', version: 1, title: 'Native language name', locale: 'xx',
  alphabet: 'abc', frequency: 'bac',
  words: ['ab', 'cab'], bigrams: ['ab', 'ba'],
  sentences: ['Ab cab.'], punctuation: ['.', ','],
  tasks: ['letters', 'words', 'bigrams', 'sentences', 'punctuation', 'mixed']
});
```

Новый пакет можно разместить отдельным классическим скриптом после
`languages.js` и до `app.js`. Карта создаёт языковую ветку из общего механизма,
без новых условных режимов в обработчике ввода. Для специфического письма,
чьих графем ещё нет в модели, сначала нужны сегментация и тесты.

Доступность материала определяется выбранной раскладкой и геометрией.
Обязательные символы узла не отбрасываются молча. Диагностика может провести
доступную часть, явно перечислив непокрытые символы. Прямые символы,
модификаторы и составные маршруты определяет реестр раскладок, не пакет языка.
