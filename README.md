# Typing Trainer — платформа 2.0

Тренажёр слепой печати для знаков, цифр и смешанного русско-английского текста (раскладки Russian – PC и English (US)). Дополняет keybr.com: буквы тренируются там, а здесь — знаки, цифры и переключение раскладки.

Статический сайт `index.html` + локальные модули `platform/`, без сборки и внешних runtime-зависимостей. Для разработки: `python3 -m http.server 8765 --bind 127.0.0.1`. Работает через GitHub Pages; данные остаются в localStorage браузера.

Новая платформа: независимые UI ru/en, материалы ru/en/fr/de, реестр семи раскладок, диагностика, 42 открытых учебных узла, мастерство, XP и достижения. Архивные macOS-карты экспериментальны, ISO требует аппаратной проверки. Старые режимы 1.x сохранены. Подробности: [архитектура](docs/ARCHITECTURE.md), [раскладки и источники](docs/LAYOUTS.md), [ручная проверка Zen](docs/ZEN_TESTING.md).

Тесты: `node tests/trainer.test.js` (нужен Playwright с Chromium).

Резервные копии: в «Настройках» доступны экспорт JSON и импорт с предварительным
просмотром и подтверждением полной замены. Формат, ограничения, восстановление
после сбоев и безопасная ручная проверка описаны в [docs/BACKUPS.md](docs/BACKUPS.md).
Дополнительные регрессионные тесты: `node tests/backup.test.js`.
План развития: [docs/ROADMAP.md](docs/ROADMAP.md).

Полный набор тестов: `node tests/run.js`.
Модель времени: [docs/TIMING.md](docs/TIMING.md).
Стабилизация и ручная проверка в Zen: [docs/STABILIZATION.md](docs/STABILIZATION.md).
